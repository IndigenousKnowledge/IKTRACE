# IKTRACE: A Natural Language Processing Framework for Identifying Indigenous Knowledge Representation in Academic Literature  

This repository contains the implementation and research outputs for the associated publication.

The project introduces a community-informed taxonomy and a multi-method NLP pipeline for identifying Indigenous Knowledge (IK) representations in academic literature in alignment with Indigenous Data Sovereignty principles. 

Raw source documents are not included in this repository due to copyright restrictions.

The LLM-based extraction component described in the paper (LlamaExtract) is not included, as its outputs are undergoing further validation.


## Indigenous Data Sovereignty and Ethical Use  

This project follows Indigenous Data Sovereignty principles and community-engaged research practices.  

Users of this repository must:  

- Respect Indigenous intellectual sovereignty  
- Avoid misuse or misrepresentation of Indigenous Knowledge  
- Cite the associated publication appropriately  
- Refrain from commercial reuse of derived knowledge representations without community engagement  

Some materials are intentionally excluded to ensure responsible data stewardship.  


## Repository Contents

This repository includes:  

- Processed paragraph-level JSON files  
- Indigenous Knowledge taxonomy domains  
- GLiNER entity extraction outputs  
- Semantic similarity analysis outputs  
- KeyBERT keyword extraction outputs  
- Knowledge graph export files  
- NLP pipeline implementation code  


## Repository Structure

- **`/data`**: Contains processed paragraph-level JSON files, Indigenous Knowledge taxonomy resources, and exported knowledge graph files.  
- **`/outputs`**: Stores the outputs generated by the NLP pipeline, including GLiNER entity extraction results, semantic similarity analysis outputs, and KeyBERT keyword extraction results.  
- **`/src`**: Contains source code for the IKTRACE pipeline, including implementations for semantic similarity analysis, named entity recognition, and keyword extraction.  
- **`requirements.txt`**: Lists the Python dependencies required to run the pipeline.
